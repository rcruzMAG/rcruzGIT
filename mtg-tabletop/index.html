Planar Table

A 3D tabletop for Magic: The Gathering — sit down, play, and (if it goes badly) throw a sandal.
The game client did not start. Run the server (npm install && npm start in mtg-tabletop/) and open http://localhost:8080 — this page cannot be opened as a plain file.
The deck is checked and imported when you host or join.
